# Put the app online (Streamlit Community Cloud, free, about 5 minutes)

1. Open **share.streamlit.io** → **Continue with GitHub** → allow access to `shaheen-abdallah/or-decision-lab`.
2. Click **Create app** → **Deploy a public app from GitHub**.
3. Repository `shaheen-abdallah/or-decision-lab` · Branch `main` · Main file path `app/Home.py`.
4. *App URL*: pick a name, e.g. `or-decision-lab` (→ `or-decision-lab.streamlit.app`).
5. **Advanced settings** → Python **3.12** → Save. No secrets needed.
6. Click **Deploy**. The first build installs OR-Tools and takes 3–5 minutes.
7. Copy the URL into the README line "Live app" and your CV.
